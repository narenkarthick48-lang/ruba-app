# 🌌 Ruba — A Different Kind of Chat

Ruba is a next-generation real-time chat web application
designed with a unique, immersive interface.

## ✨ Features

- 🔐 Secure Google Authentication
- 💬 Real-time private messaging
- 👤 User profiles
- 🟢 Online / offline status
- ✍️ Typing indicators
- 🔔 Notifications
- 🖼️ Image sharing
- 🔎 Conversation search
- 📱 Mobile-first design
- 🌌 Unique animated chat experience

## 🛠️ Technology

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Firebase Storage

## 🔐 Authentication

Ruba uses Google OAuth authentication.
Users authenticate directly through Google.
Passwords are never collected or stored by Ruba.
